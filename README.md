# Enterprise AI Operating System

## Overview

Enterprise AI Operating System is a production-grade multi-agent AI platform that simulates an enterprise organization.

The platform combines:

- Multi-Agent AI
- LangGraph
- Retrieval-Augmented Generation
- Knowledge Graphs
- PostgreSQL
- Qdrant
- Neo4j
- Redis
- Enterprise Security
- Explainable AI
