# User guide

Sign in, then open **Operations Center**. Authorized users can launch an HR request, project-risk review, or document-intake workflow. HR and sensitive document flows pause in `awaiting_approval` until an authorized human decides the request.

The dashboard shows portfolio, workforce, knowledge, and agent activity. Operations Center adds live project/AI indicators, workflow history, execution traces, and a button to run the acceptance evaluation suite. All operational actions are auditable.
